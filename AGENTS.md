# IA (X).SS — All Security Stack

Antes de trabalhar em código, leia `SKILL.md`. Carregue as referências indicadas conforme a stack e o tipo de mudança.

- Execute um checkpoint após mudanças em autenticação, autorização, banco, APIs, uploads, pagamentos, segredos, dependências ou infraestrutura.
- Antes de declarar o projeto concluído, publicado ou pronto para deploy, execute o portão final completo.
- Não aprove com achado crítico/alto aberto nem quando faltar evidência indispensável.
- Não execute testes ativos ou destrutivos contra produção sem autorização explícita.
- Nunca revele valores de segredos; redija-os e recomende revogação/rotação.
- Entregue o relatório conforme `references/report-template.md`.
